# Stable procedures

- Live pose and readiness come from guardian_observe, never this file.
- Objective/coverage/candidate notes live in the server's mission journal and the
  current conversation. Use guardian_remember and guardian_memory.
- Pilot confirmation is required for launch; pilot flight enable is separate.
- Mode ceiling is configured on the server. The agent cannot raise it.
- Current flight limits: 35 m server radius, 5–30 m altitude, moves ≤5 m.
- Human review is required for every possible person match.
- Do not keep bearer tokens, leases, personal identities or raw location history here.
